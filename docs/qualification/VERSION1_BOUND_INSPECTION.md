One pure shared delivery comparison is called after existing schema/run/command
checks, before parent._finished and before MCP clears its retained launch. A
positive response requires verified publication status, no error/blockers,
exit0, target verification and the CURRENT receipt. Failed raw responses retain
their original facts/error. Mismatch poisons the existing finite owner and keeps
the same actual launch; it never authorizes retry. Parent and MCP keep their
existing finalizers and primary/secondary error behavior.

These small adapters address caller/result substitution and loss of transport
facts. They do not authenticate code from matching hashes, replace Core intent,
write another receipt, add a queue/journal/version store, or create recovery
semantics. The response remains the existing raw command1.0 frame. A verified
highlevel version publisher/correlator is still unfinished; file2/bundles/version2
are not enabled. The optional payload hash does not promise current upstream
source freshness: existing stored bytes are independently verified either way.
